1.0 - October 27, 2026
    - Initial release.

1.1 - November 1, 2026
    - Fix EXIF data not saving correctly.
    - Replace the generic icon in the titlebar with the Baldnerd's 360 Portrait Studio icon.
    - Include loaded image filename in title bar.
    - Protect against accidentally overwriting source images and photos not created by Baldnerd's 360 Portrait Studio.
    - Can now drag-and-drop images onto the application to load an image.
    - Added Image Info dialog which shows EXIF data, geocoordinates on OpenStreetMap, and both source and export dimensions.
    - Improved the quality of the brand and camera model detection and included links to buy.
    - Minor improvements to the About dialog.

1.2 - Work in Progress (unstable)
    - Created a custom digital asset manager (DAM) to replace the old OS dialogue when Load Image is clicked. The DAM allows visual browsing of 360 images with previews.
    - DAM adds a checkmark to photos that have already been opened previously to ease navigating large folders of files.
    - Previously I was doing a string comparison for the version check. Changed to a numerical evaluation so the update window can recognize when a user is on a version newer than the current release version, prompting a note about it being a development version.
    - Moved icons into a nested folder so not all assets are compiled in (reduce filesize of binary).
    - Added geocoordinates to all 360 photo samples.
    - Improved OpenStreetMap link when geocoordinates are detected.
    - Updated all sample exports to v1.2.
